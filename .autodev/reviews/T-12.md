  is always the full relative path, never the basename, verified by code reading (no live

  common, realistic repo shape (any file ever renamed) producing a materially misleading

  a gap in AC4's chosen git invocation as it is a defect in `witness.ts`'s implementation of

   own parse-check (tree-sitter's ERROR-node count) is more lenient than real Python here
   (Angle 4/5).
