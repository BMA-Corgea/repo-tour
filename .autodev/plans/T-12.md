# Plan — T-12 (branch `feature/T-12-build-engine`, worktree `../repo-tour-T-12`)

Delivery target: local ticket branch with commits; the orchestrator merges to `main` after T-11.

1. **`src/build/types.ts`** — the §4.2 model verbatim, plus `Range { startLine; endLine }`, `CheckReport { symbols: {name, kind, status: 'present'|'missing'|'extra'}[]; imports: {raw, status: 'present'|'missing'}[]; parseErrors: number; ok: boolean }`, and `plan.reproduce: string[]` (generated / vendored / lockfile paths the automated writer copies but never teaches). Verify: typecheck.
2. **`src/build/witness.ts`** — for each repo root in `digest.manifest.repos`: one `git log --diff-filter=A --name-only --format=%H%x09%ad%x09%s --date=short` parsed into `Map<path, {sha, date, subject}>` (first appearance wins, so iterate oldest-first with `--reverse`); no repo or no history → nulls. Verify: a fixture with 3 commits gives the first-add commit per file; a non-git fixture gives nulls.
3. **`src/build/plan.ts`** —
   a. chapters: `buildArchitecture(digest)` parts ordered by layer bottom-up (foundations first); ties by part score; a single-part result falls back to subsystem tiers; a lone chapter is fine.
   b. files per chapter: `source` + `structural` only; Kahn's topological order over the import graph restricted to the chapter's files (leaves first); ties by witness date, then `ranked` score desc, then path. Test files (`*.test.*`, `*.spec.*`, `test_*.py`, `*_test.py`, or under `test/` | `tests/`) go immediately after the file they name (strip the test marker, match by basename), else at the chapter's end.
   c. steps: one `shape` per chapter (question: why this part exists, templated from the architecture brief); one `file` per file (question templated from exports and imports: "This module exports A, B and imports X, Y — why does this get its own module?"); `symbol` steps for exported symbols sorted by span desc, capped at 5; `dependsOn` = the file steps of resolved imports; `scaffold.loadBearing` = the symbol steps' ranges, `boilerplate` = the complement within `[1, loc]`; `decision.options` = `[{ id: 'author', label: 'What the author did', consequence: <one line from exports/imports>, taken: true }]`; `why` = the symbol's `doc` (symbol steps) or the file's first exported doc (file steps) with `whySource: 'docstring'`, else `'not inferable from the source'` with `'none'`; `witness` from step 2; ids = first 16 hex of `sha256(file + ' ' + kind + ' ' + symbolName)`. `generated` / `vendored` / `lockfile` files go to `plan.reproduce`.
   d. `plan.cost` mirrors `InterpretCost` with `metered: false` and zero calls (interpretation is T-13's).
   Verify: `test/build.test.ts` on a synthetic git repo with a 4-file import DAG, one test file and one generated file — exact expected order, kinds, caps, reproduce list.
4. **`src/build/stub.ts`** — TS/JS: keep the range's first line, replace the body with `{ // TODO(step N): <question> }` (arrow functions get `=> { ... }`); Python: keep the `def` / `class` line, body `    raise NotImplementedError  # TODO(step N): <question>`; everything outside the ranges is copied verbatim. Verify: stubbed TS, JS and Python fixtures each parse with `extract()` reporting `parseErrors === 0`.
