## The risky part, and how it actually went

The write-ahead handoff (commit `943f382`) called out plan step 3a as the risk: a small
fixture can make `buildArchitecture` yield fewer than two parts, and the tier-fallback
path needed its own test rather than an assumption that it degrades gracefully from the
primary path. It did need its own fixture (two single-file directories, each individually
too small for `chooseSubsystems`'s `directCode >= 2` filter), and that fixture caught a
REAL bug before it shipped (see Surprises) — the write-ahead was worth doing.

## Surprises, in the order they were found

1. **`git log --diff-filter=A --name-only --format=...` puts the blank line right AFTER
   each commit's header, not between commits.** A parser that resets "current commit" on
   every blank line drops every filename, because the reset fires immediately before the
   names it should capture. `witness.ts` detects a header by shape (tab-delimited
   `sha\tdate\tsubject`) instead. Verified by hand with a throwaway repo before writing
   the real parser — worth a `kb/wiki/lessons.md` entry (not added here: this ticket's
   touched set is `src/build/**` + `src/cli.ts` + tests + this handoff; a wiki edit is a
   small, separate, easy follow-up for whoever picks up T-13 or a later repo-tour ticket).
2. **A raw NUL byte reached the file on disk from a template-literal separator that was
   only ever meant to be a plain, printable character**, in `chapterEdges`'s dedup key.
   Whatever layer carried the file content from
   this session's own tool call into the file interpreted the escape rather than passing
   it through literally, so a real `0x00` byte landed in `src/build/plan.ts` — which then
   made plain `grep` treat the entire file as binary and silently print nothing, no error,
   for every query. Found because a routine `grep -c "function" plan.ts` returned nothing
   at all, which should never happen. Fixed by replacing the byte with a plain space
   (`python3 -c "...replace(b'\x00', b' ')..."`, operating on raw bytes so the fix itself
   could not repeat the mistake) and re-verified with `file`/`grep`. **Lesson for anyone
   editing files as this kind of agent: never put a `\uXXXX` escape literally in file
   content passed through a tool call; if a template literal genuinely needs one, write
   it in a way that cannot be pre-decoded, or add it with a follow-up edit and check the
   resulting bytes.**
3. **`extract.ts` marks a class's public methods `exported: true` whenever the class
   itself is exported**, so a class and its own methods can both be candidates for the
   5-symbol cap, with the class's range fully containing its methods' ranges. Resolved by
   sorting candidates by span descending and skipping any that overlap one already
   chosen — not spec text, a considered resolution of a case the spec did not anticipate.
4. **A tree with NO `.git` anywhere makes `rollup.ts#kindFor` mislabel the scan root
   itself `kind: 'subsystem'`** (no `RepoRef` means `isRepoRoot` is never true, even for
   the root), which would have given the tier-fallback path a phantom, file-less chapter.
   `tierSeeds()` now excludes `path === ''`, mirroring `chooseSubsystems`'s own existing
   guard, plus a general safety net in `buildPlan` itself that drops any seed that ends
   up owning zero files directly (belt and suspenders — the second guard would have
   caught this on its own even without the first).
5. Nearly repeated `test/pipeline.test.ts`'s own documented "paths with spaces in them"
   defect while writing the AC8 schema test: `new URL(import.meta.url).pathname`
   percent-encodes the space in this project's own directory name
   (`.../Coding Projects/...`). Used `fileURLToPath` instead, per that file's own lesson.
6. `code-map.mjs`'s `SKIP_DIRS` treats any directory literally named `build` as a
   build-output directory (same bucket as a root-level `dist/` or `build/`), so
   `src/build/**` — this ticket's own module — is invisible to the regenerated
   `kb/CODE-MAP.md`. Not fixed (the script is AutoDev plugin infrastructure, out of this
   ticket's touched set); flagged here for whoever next touches that script, or names a
   source directory `build` in any repo it runs against.
